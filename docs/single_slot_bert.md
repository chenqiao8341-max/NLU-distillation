# Single-Slot BERT Extraction

## Suitability

`author_org` is mostly suitable for BERT extraction:

- `author_name` and `author_institution` are query-visible spans.
- `author_name英文变体` should stay rule/lexicon generated after extraction, not predicted by BERT.
- Company/sponsor names inside this task are a data-policy issue, not a BERT capability issue.

`org_country` is suitable for BERT extraction when we follow the prompt constraint strictly:

- `机构名称` and `国家` must come from the query text.
- The prompt forbids inferring country from institution name, so this is an extractive NER task rather than a normalization task.

`time_if` is only partly suitable for pure BERT:

- BERT can extract visible triggers such as `2024年`, `近3年`, `最新`, `IF >= 3`, `高质量`.
- The final output requires normalization and defaults, for example `近3年 -> 2023-01-01` and `高质量 -> IF >= 3`.
- Therefore BERT should be used as a trigger extractor, followed by deterministic rules for final `filter_*` fields.

## Why Split Slots

The previous combined tasks mix several decisions in one model:

- `author_org`: author and institution labels compete in the same sequence.
- `org_country`: institution and country have different frequency and boundary patterns.
- `time_if`: date/time triggers and IF triggers follow different lexical rules.

Single-slot models make each model answer one question:

- `author`: extract author spans.
- `institution`: extract organization/institution spans.
- `country`: extract explicit country/region spans.
- `time`: extract time/date recency triggers.
- `impact_factor`: extract IF threshold triggers.

At inference time, a business task can call multiple slot models and merge outputs:

- `作者和机构` -> `author` + `institution`, then generate author variants.
- `机构和国家` -> `institution` + `country`.
- `时间和if值` -> `time` + `impact_factor`, then normalize with rules.

This should reduce label interference and makes per-slot thresholds/postprocessing easier to tune.

## Training

The existing BIO trainer can train these slots:

```bash
/home/qiao/work/llm_env/bin/python scripts/train_eval_modernbert_ner.py \
  --tasks author institution country time impact_factor \
  --data-root data/processed_single \
  --output-root experiments/modernbert_single_slot \
  --report-dir reports/modernbert_single_slot \
  --model-path /home/qiao/models/BERT/ModernBERT-base \

  --epochs 5 \
```

## Comparison

These baselines are directional references, not a strict same-test-set comparison. The single-slot reports use the manually reviewed eval snapshots as test data, while older reports were produced from their existing processed splits.

Existing combined BIO baseline:

| task | F1 | notes |
| --- | ---: | --- |
| author_org | 0.9190 | AUTHOR F1 0.9294, INSTITUTION F1 0.8627 |
| org_country | 0.6929 | COUNTRY F1 0.6772, INSTITUTION F1 0.6959 |

Existing GlobalPointer baseline:

| task | F1 |
| --- | ---: |
| author_org | 0.6090 |
| org_country | 0.7378 |
| time_if | 0.9162 |

Current read:

- Single-slot `author` is production-plausible but does not beat the combined `author_org` BIO AUTHOR score.
- Single-slot `institution` has useful recall but too many false positives, especially on `机构和国家`.
- Single-slot `country` has better F1 than combined BIO country, mainly by high precision; recall still needs work.
- Single-slot `time` and `impact_factor` are not good enough as trained. `time_if` should stay as a rule/normalization-heavy task or use the existing GlobalPointer result as the stronger span baseline.
- Splitting remains a good architecture for controllability, but the first train shows it should be adopted selectively: author/country are promising, institution needs threshold/postprocess tuning, and IF should probably be rule based until there is more positive data.

## Business Eval

For comparison with SFT models, run the single-slot BERT models against the same offline eval JSON datasets and score with `/home/qiao/work/nlu-evaluator/main.py::evaluate_predictions`.

```bash
/home/qiao/work/llm_env/bin/python scripts/eval_single_slot_bert_business.py \
  --tasks 作者和机构 机构和国家 \
  --output-prefix reports/modernbert_single_slot_business/single_slot_bert_eval_20260610
```

`作者和机构` calls the `author` and `institution` slot models, then generates `author_name英文变体` from the extracted authors. `机构和国家` calls the `institution` and `country` slot models and merges the two fields.

Observed error modes:

- `country` misses explicit country mentions such as `中国` in guideline titles.
- `institution` often finds useful spans but can truncate long Chinese titles or include near-institution text.
- `author_name英文变体` is sensitive to variant-generation policy; Partial/F1 is much more informative than strict EM for this field.
